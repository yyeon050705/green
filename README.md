# green — 게시판 프로젝트

팀 협업으로 개발하는 게시판(Board) 웹 애플리케이션입니다.

## 지원 기능

- 회원가입 / 로그인 (인증)
- 게시글 CRUD (작성 / 조회 / 수정 / 삭제)
- 댓글 기능
- 좋아요(추천) 기능
- 검색 / 페이지네이션

## 기술 스택

- Backend: Node.js (Express)
- Frontend: React

## 폴더 구조

```
/backend   - Express 기반 REST API 서버
/frontend  - React 기반 클라이언트
/docs      - 프로젝트 문서 (브랜치 전략, 협업 가이드 등)
```

## 협업 가이드

팀 역할 분배 및 브랜치 전략은 [docs/BRANCH_STRATEGY.md](docs/BRANCH_STRATEGY.md) 문서를 참고하세요.
