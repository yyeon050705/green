    API 설정

    V-World(브이월드) Open API는 www.vworld.kr/dev 에서 발급받은 인증키가 필요합니다. 서버의 .env에 VWORLD_API_KEY를 설정해두면 여기 입력하지 않아도 동작합니다. 여기에 입력하면 이 브라우저에서 보낸 요청에 한해 서버 기본값 대신 사용됩니다.

    데이터셋 코드는 V-World 개발자센터의 데이터 API 문서에서 계정에 제공되는 실제 코드를 확인해 입력하세요. (예: 용도지역지구, 연속지적도 등 레이어별 코드가 다르며 서비스 제공 범위에 따라 달라질 수 있습니다.)
